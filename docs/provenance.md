# 来源与整理记录

## 原始材料

- `project10MHz.rar`：用户提供的 Vivado 工程，归档目录名为 `project10MHz`。
- 《数字系统设计实验报告》：用户提供的 DOCX，含代码附录、仿真截图与实机照片。
- 项目于 2025.07–2025.08 开展，报告于 2025.12 整理／提交，日期用途不同。

原始文件保留在用户本地，没有覆盖，也没有把整份报告或 RAR 放入公开目录。`source-map.json` 记录原相对文件名、原文件 SHA256、来源编码和整理后位置；不包含本机绝对路径。

## 源码选择

原 `adc_frequency_meter.v` 同时内嵌 `adc_schmitt`、`sync_edge`、`gate_counter`、`period_counter_avg`、`freq_smooth_iir`，工程又引用同名独立文件。本仓库保留其顶层 `adc_frequency_meter`，辅助模块统一采用各自独立文件。原综合日志也出现了这些独立文件路径，但日志异常结束，不能据此认定历史最后一次构建成功。

独立 `adc_schmitt.v` 有 `MID_CODE`、`HYS` 参数，能与上层实例匹配，采用固定中心码滞回。原内嵌版本使用历史极值更新阈值，没有 `MID_CODE` 参数，两者不能混用。整理版明确采用前者，不宣称具备后者的自适应功能。

## 首次整理的修改

1. 将混合 UTF-8／GB18030 源文件统一为 UTF-8、LF，保留原逻辑和原有注释。对已知错误注释增加说明。
2. 删除同名辅助模块的重复定义，确立唯一源列表 `rtl/files.f`。
3. 将 `DDS.v` 内的正弦 ROM 抽为 `rtl/sin_rom.v`。原 `real/$sin/$rtoi` 初始化改为静态 MEM 文件，保留 `128 + trunc(127*sin(2*pi*i/256))` 规则、一拍读出和 256×8 位宽；数据由检查脚本逐项核对。
4. 不混入原 IP 的 COE 表。原 COE 采用不同的取整数据，部分样本与行为 ROM 相差 1 LSB。当前选择原 `DDS.v` 行为模型的样本约定，因此不声称与历史 FPGA bitstream 完全等价。
5. 将 `gate_counter` 的 `GATE_TIME` 移入模块参数端口列表，默认值保持 1000000。此项消除 slang 在命名参数覆盖时的展开错误；没有修复计数边界或测量逻辑。
6. 数码管身份展示模式的学号后四位改为 `0000`。这项公开版脱敏会改变演示编号，其他显示模式不因此改变。
7. 增加检查／仿真入口、Vivado 建项脚本、README、图片索引、已知问题和项目结构图。

首次整理没有修复测量算法。本次后续修复由用户明确要求，修改范围和回归结果记录在 warnings-and-fixes.md；不将它们包装成2025年课程原有成果。

## 图片与署名

`assets/` 中的实验图片从原 DOCX 媒体中直接提取，未修图、未制造测试结果。`architecture.svg` 是根据代码重新绘制的结构示意图。原完整报告含个人学号等信息，本仓库只放不包含这些字段的项目说明 PDF。

课程与第三方素材的具体贡献没有由归档单独证明，因此 README 使用“课程项目”描述，不声称全部模块从零独立原创。正式发布前可补充课程提供代码／IP 的明确来源。未擅自添加 MIT、Apache 等授权。

在本地保留首次整理快照后，按用户要求修复IIR、计数边界、显示补偿、扫频和ROM启动等问题，补充9组断言回归。原归档SHA256保持不变；source-map.json另记本次文件SHA256。详情见 [warnings-and-fixes.md](warnings-and-fixes.md)。

## 补充原始COE后的数据统一

用户另行提供 `sin_wave_256x8.coe`，SHA256为 `2691202835a3aa97c2c358f90b9d9443681ce533d1b481723ea0cbd4901bf5ad`，与原RAR的 `project_multi_wave.ip_user_files/mem_init_files/sin_wave_256x8.coe` 字节一致。

当前数据选择更新：保留原COE，新增 `build_rom.py` 将256个十进制码值逐项转换为MEM。首次整理的行为模型截断表不再是当前波形源；两表144点相差1LSB。本次明确记录数据变化，保留先前比较结果为历史证据，不假称历史截图是新表实机复测。

增加COE格式、深度、范围、进制和往返转换检查，以及ROM全部256地址的同步读出仿真。项目主简历、实验报告和原始RAR未改动。
