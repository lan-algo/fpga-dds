# 41条警告与本次修复

原检查使用 pyslang 12.1.0：0 errors / 41 warnings。修复后相同工具、相同RTL范围为0 errors / 0 warnings；没有关闭警告规则。

## 原警告分布

| 类别 | 数量 | 实际含义 |
| --- | ---: | --- |
| 隐式位宽截断 | 30 | 24条来自十进制数字拆分，其余来自频率/占空比结果缩窄；必须先确认数值范围，不能只加类型转换 |
| 有符号/无符号比较 | 4 | 计数寄存器与整数参数比较；当前正数默认值下通常不是直接故障，现统一位宽与无符号参数 |
| 不同类型参与算术 | 4 | 16位占空比值与32位常量运算；现先明确零扩展 |
| 无符号算术右移 | 1 | IIR下降输入的差值回绕，可造成巨大错误输出 |
| 常量超过声明位宽 | 1 | 未使用的4位year_str承载8位字面量；已删除死参数 |
| 未连接输出 | 1 | 手动控制模块额外产生ROM输出，但顶层未使用；已去掉冗余ROM/累加器和输出 |

数码管模块贡献29条警告，因此41条不是41个独立运行故障。部分真正的逻辑错误不会产生警告，仍需仿真。

## 可复现故障和修复

| 问题 | 修复前的回归表现 | 实际修改 |
| --- | --- | --- |
| IIR无符号差值回绕 | 输入下降时输出3997 → 1073744821 | 根据升降方向计算非负差值，再加减步长；小差值至少走1，避免卡在目标附近 |
| 闸门窗口边界 | 第10个采样周期仍输出0，漏掉指定关窗结果 | 严格计GATE_TIME个周期，包含当前边沿，使用宽乘法按参考时钟/窗口长度换算 |
| 周期法启动 | 只到4个边沿就输出60，实际应先等4个完整周期 | 第一个边沿只建立基准；跨周期差值累加；默认约2秒无边沿清零 |
| 低频选择启动 | 快速结果20已经就绪，仍输出0 | 慢速结果未就绪时先使用有效快速结果 |
| 占空比边界 | 5高5低的50%信号显示44% | 统一同步后边沿；完整周期计数；当前上升沿纳入下一周期；64位乘除、整数四舍五入 |
| 显示加3 | 输入0却显示3 | 移除固定补偿；数字提取先限制到8位可显示范围，余数0..9明确取4位 |
| 扫频初始化/切档 | 初始频率显示与控制字不一致，切档可停留在新范围外 | 常量异步复位，连续逻辑选择范围，越界回到新下界；显示直接由当前控制字换算 |
| 顶层首次ROM读出 | 复位停止派生时钟，恢复后的首次正弦输出出现X | DDS等待ROM完成首次同步读出，再开放正弦数据；时序输出统一非阻塞赋值 |

频率计算保留64位中间值，依据11位控制字对应的实际范围再取32位。计数器宽结果使用明确边界或饱和处理，不是简单把警告遮掉。
